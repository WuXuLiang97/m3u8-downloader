M3U8 下载工具帮助文档

工具介绍

M3U8 下载工具是一个多线程的命令行工具，用于下载 M3U8 格式的视频播放列表并将其合并为 MP4 文件。该工具支持以下功能：

  • 多线程并行下载，提高下载速度
  • 支持多个 M3U8 URL 同时下载
  • 为每个 URL 指定单独的输出文件名
  • 实时显示下载进度和速度
  • 自动清理临时文件
  • 支持从文件读取任务列表

基本命令格式

m3u8-downloader.exe [参数] [URL1] [输出文件1] [URL2] [输出文件2] ...

命令示例

1. 下载单个 M3U8 播放列表

m3u8-downloader.exe -threads 10 "https://example.com/playlist.m3u8" "output.mp4"

2. 下载多个 M3U8 播放列表

m3u8-downloader.exe -threads 10 "https://example.com/playlist1.m3u8" "video1.mp4" "https://example.com/playlist2.m3u8" "video2.mp4"

3. 使用默认命名规则

m3u8-downloader.exe -output "video.mp4" -threads 10 "https://example.com/playlist1.m3u8" "https://example.com/playlist2.m3u8"

这会生成 video_1.mp4 和 video_2.mp4

4. 从文件读取任务列表

m3u8-downloader.exe -file "tasks.txt" -threads 5

tasks.txt 文件格式示例：

https://example.com/playlist1.m3u8,video1.mp4 https://example.com/playlist2.m3u8,video2.mp4 https://example.com/playlist3.m3u8,video3.mp4

参数说明

参数 说明 默认值
-threads 下载线程数 10
-output 默认输出文件名（当未指定具体输出文件名时使用） output.mp4
-temp 临时文件目录 temp
-file 包含任务列表的文件路径（格式：URL,output.mp4） 无

常见问题

1. 下载失败，显示 "unexpected EOF" 错误

这通常是由于网络连接不稳定或服务器响应不完整导致的。建议：

  • 检查网络连接是否稳定
  • 尝试减少线程数，避免网络拥塞
  • 重新运行命令，可能会成功下载

2. 下载失败，显示 "status code 404" 错误

这表示 M3U8 URL 不存在或已经失效。建议：

  • 检查 URL 是否正确
  • 确认 URL 格式是否正确，例如是否需要添加前缀 0（如 001 而不是 1）
  • 尝试使用其他有效的 M3U8 URL

3. 下载速度很慢

建议：

  • 增加线程数（如 -threads 20）
  • 检查网络连接速度
  • 确认服务器是否限制了下载速度

4. 生成的 MP4 文件无法播放

这可能是由于下载过程中出现错误或合并失败导致的。建议：

  • 确保所有片段都成功下载
  • 检查 FFmpeg 是否正确安装（工具会优先使用 FFmpeg 合并）
  • 重新运行命令，确保下载过程不中断

使用技巧

  • 对于大型视频，建议使用较多的线程数（如 15-20）以提高下载速度
  • 对于网络不稳定的情况，建议使用较少的线程数（如 5-10）以提高稳定性
  • 使用 -file 参数可以方便地批量下载多个视频
  • 确保目标目录有足够的磁盘空间

提示：点击命令右侧的 "复制" 按钮可以快速复制命令到剪贴板，然后在命令提示符或 PowerShell 中粘贴使用。
